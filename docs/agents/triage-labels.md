# Метки triage

Навыки используют пять канонических ролей triage. Таблица связывает роли с
метками GitHub этого репозитория.

| Роль | Метка GitHub | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Требуется оценка сопровождающего |
| `needs-info` | `needs-info` | Ожидается дополнительная информация от автора |
| `ready-for-agent` | `ready-for-agent` | Задача полностью описана и готова для автономного агента |
| `ready-for-human` | `ready-for-human` | Для реализации требуется человек |
| `wontfix` | `wontfix` | Задача не будет выполнена |

Когда навык ссылается на роль triage, используй соответствующую метку из этой
таблицы.
