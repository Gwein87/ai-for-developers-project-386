# Применение флоу Мэтта

## Источник правил

Спецификация флоу — установленный навык `ask-matt/SKILL.md`.
Он определяет выбор маршрута, порядок этапов и условия переходов.
Инструкции выбранных им навыков определяют действия и критерии завершения.

Этот документ связывает проект со спецификацией. Порядок этапов и правила
переходов здесь не дублируются и отдельно не задаются.

## Подключение спецификации

При начале задачи и возобновлении работы в новом чате:

- Найди и прочитай полный `ask-matt/SKILL.md` в доступном каталоге навыков.
  Если он не указан в каталоге, проверь `~/.agents/skills/ask-matt/SKILL.md`.
- Восстанови состояние задачи по текущему чату, связанному GitHub Issue
  и рабочему дереву. Используй документы проекта по ссылкам из `AGENTS.md`.
- Определи применимый маршрут и текущий этап по спецификации флоу.
  Прочитай полные `SKILL.md`, на которые этот этап ссылается.
- Назови текущий этап и применяемые навыки. Выполняй их требования к действиям,
  согласованиям, артефактам и завершению, включая вложенные вызовы навыков.

Если отдельного инструмента Skill нет, прочитай соответствующий `SKILL.md`
доступным инструментом и выполни инструкции. Одно упоминание имени навыка
не считается его применением.

Если спецификация или нужный навык не найдены, сообщи точное имя недоступного
источника и запроси его расположение. Не восстанавливай порядок по памяти.
При расхождении фактической работы с выбранным маршрутом укажи пропущенные
требования; не отмечай их выполненными задним числом.
